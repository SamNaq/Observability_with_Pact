# Demo Observability - Pact Contract Testing

A comprehensive demo application showcasing Pact consumer-driven contract testing with full observability using Prometheus metrics, structured logging, and Grafana dashboards.

## 🚀 Quick Start

```bash
# 1. Install dependencies
npm install

# 2. Build the project
npm run build

# 3. Start services (in separate terminals)
npm run dev:provider    # Terminal 1
npm run dev:consumer    # Terminal 2

# 4. Run tests
npm run test:consumer
npm run test:provider
```

## 📋 Project Structure

```
.
├── consumer/              # Consumer service
├── provider/              # Provider service
├── src/                   # Shared utilities (logger, metrics, middleware)
├── tests/                 # Pact tests (consumer & provider)
├── pact_contract/         # Pact contract files (generated by tests)
├── docs/                  # Documentation
├── scripts/               # Utility scripts
├── grafana/               # Grafana configuration (optional)
└── prometheus/            # Prometheus configuration (optional)
```

## 🎯 Key Features

- **Consumer-Driven Contract Testing** with Pact
- **Local Pact Contracts** stored in `pact_contract/` (no Docker required)
- **Structured Logging** with Winston
- **Prometheus Metrics** collection
- **Grafana Dashboards** (optional, requires Docker)
